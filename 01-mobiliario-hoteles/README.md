## 🚀 Cómo visualizar la web
Puedes abrir directamente el archivo `index.html` con cualquier navegador web moderno, o iniciar un servidor local:

```bash
# Con Python
python -m http.server 3000

# O con Node.js / npx
npx serve .
```

Abre en tu navegador: `http://localhost:3000`
