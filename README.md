# 🌐 Proyectos Web Frontend e Innovación Digital

Portafolio de desarrollos web (HTML5, CSS3, JavaScript) y propuestas de transformación digital e inteligencia artificial aplicadas a distintos sectores empresariales (turismo, salud, restauración y formación).

Cada proyecto está estructurado como un caso práctico real, combinando diseño centrado en el usuario, arquitectura frontend limpia y visión estratégica de negocio.

---

## 📂 Catálogo de Proyectos

### 💻 Desarrollo Web y Aplicaciones Frontend
* **01. [Mobiliario Hoteles](./01-mobiliario-hoteles/)** — *Landing page* corporativa y catálogo visual B2B para equipamiento hotelero y restauración.
* **02. [Clínica Dental](./02-clinica-dental/)** — Ecosistema web multi-página enfocado en captación de pacientes y educación sanitaria.
* **03. [Landing Curso IA](./03-landing-curso-ia/)** — Página promocional de conversión, estrategia de email marketing y carrusel visual interactivo.
* **05. [App Taquería](./05-app-taqueria/)** — Aplicación web interactiva de carta digital, flujo de pedidos y panel de gestión desarrollada con JavaScript modular.
* **06. [Propuesta Aura Studio](./06-propuesta-aura-studio/)** — Diseño y maquetación web minimalista para estudio creativo.

### 🚀 Consultoría de Transformación Digital e IA
* **04. [Propuesta de IA y Automatización para Hotel](./04-propuesta-ia-hotel/)** — Diagnóstico estratégico, arquitectura tecnológica, automatización de procesos (RPA), atención al huésped y presentación ejecutiva de soluciones de Inteligencia Artificial para el sector turístico.

## ▶️ Cómo visualizar los proyectos en local
1. Clona este repositorio o descárgalo en tu equipo:
   ```bash
   git clone https://github.com
   ```
2. Entra en la carpeta del proyecto que desees explorar y haz doble clic sobre su archivo `index.html` (o ábrelo con la extensión *Live Server* en VS Code).
