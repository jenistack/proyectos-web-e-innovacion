# 🦷 Ecosistema Web — Clínica Dental

Conjunto de páginas web orientadas a mejorar la presencia digital, la captación de nuevos pacientes y la educación sanitaria de una clínica odontológica.

## 📂 Estructura del proyecto
* **`pagina-clinica/`:** Sitio web principal de la clínica con estilos personalizados (`styles.css`) e interactividad (`main.js`).
* **`nuevos-pacientes/`:** *Landing page* enfocada en la conversión y primera visita de pacientes.
* **`clinica-educativa/`:** Sección informativa sobre prevención y salud bucodental.

## 🛠️ Tecnologías
* HTML5
* CSS3
* JavaScript (ES6+)
