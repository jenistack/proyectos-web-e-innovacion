# Identidad de Marca (Brand Identity)

Asegúrate de aplicar estos lineamientos estéticos y de comunicación en todos los diseños, interfaces y propuestas generadas.

## 1. Colores Corporativos

*   **Primario:** `#0F172A` (Slate 900 - Para fondos principales y textos de alto contraste)
*   **Secundario (Acento):** `#3B82F6` (Blue 500 - Para botones principales y llamadas a la acción)
*   **Fondo:** `#F8FAFC` (Slate 50 - Para fondos claros)
*   **Texto Principal:** `#334155` (Slate 700 - Para legibilidad en párrafos)

*(Nota: Modifica estos colores HEX según la marca de tu cliente)*

## 2. Tipografías (Google Fonts)

*   **Titulares (Headings):** `Outfit`, sans-serif (Uso en h1, h2, h3 para un look moderno y premium)
*   **Cuerpo de Texto (Body):** `Inter`, sans-serif (Uso en párrafos y elementos de UI para máxima legibilidad)

## 3. Logos

*   **Ruta del Logo Principal:** `/assets/images/logo-principal.svg` (Usar en la barra de navegación)
*   **Logo Alternativo (Modo Oscuro):** `/assets/images/logo-blanco.svg`
*   **Favicon / Símbolo:** `/assets/images/simbolo.svg`

*(Nota: Si prefieres usar Base64 o SVG directo, puedes pegar el código aquí)*

## 4. Voz de la Marca (Brand Voice)

*   **Tono:** Premium, minimalista, directo y profesional.
*   **Estilo:** Evita la jerga excesiva. Sé claro y conciso. Las propuestas deben sentirse vanguardistas y exclusivas.
*   **Trato:** Habla de "tú" pero manteniendo el respeto y la elegancia.
