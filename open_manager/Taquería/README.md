# 🌮 Taquería El Trompo Loco · App Móvil de Pedidos para Recoger

Una aplicación web moderna, rápida y visual diseñada con enfoque **Mobile-First** para que los clientes exploren el menú, personalicen sus platillos (tortillas, verduras, salsas, extras) y preparen su pedido para **recoger en local (pickup)** con envío automático a **WhatsApp** y **Ticket Digital**.

---

Puedes abrir la aplicación directamente en cualquier navegador (Chrome, Edge, Safari, Firefox):

1. **Acceso directo en la raíz:**
   * Abre [`taqueria.html`](file:///c:/Users/elisa/Antigravity/open_manager/Taquería/taqueria.html)

## 📁 Estructura del Proyecto

* **[`taqueria.html`](file:///c:/Users/elisa/Antigravity/open_manager/Taquería/taqueria.html)**: Punto de entrada directo en la raíz del espacio de trabajo.

  * [`styles.css`](file:///c:/Users/elisa/Antigravity/open_manager/Taquería/taqueria-app/styles.css): Diseño mobile-first con tema gastronómico de alto impacto y microinteracciones.
  * [`data.js`](file:///c:/Users/elisa/Antigravity/open_manager/Taquería/taqueria-app/data.js): Catálogo de productos, precios, salsas, tortillas y extras.
  * [`app.js`](file:///c:/Users/elisa/Antigravity/open_manager/Taquería/taqueria-app/app.js): Carrito dinámico, checkout, integración WhatsApp, ticket digital y almacenamiento local.
  * [`README.md`](file:///c:/Users/elisa/Antigravity/open_manager/Taquería/taqueria-app/README.md): Guía de uso y personalización.
